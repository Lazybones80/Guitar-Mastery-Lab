# Guitar Mastery Lab

Guitar Mastery Lab is a standalone, offline-friendly guitar-learning app built in the Pick Lab visual family. It combines a sequenced roadmap, a searchable exercise library, and a daily practice planner in one local-first experience.

## Included

- 11 roadmap phases, including continuing advanced studies
- 264 authored exercises across 12 departments
- Structured exercise records with objectives, prerequisites, exact practice steps, playable material, tempo progression, variations, corrections, listening cues, mastery checks, and related work
- Native SVG fretboard diagrams for note, interval, scale, and triad exercises
- Tab and rhythm visualizations for technique, ear, rhythm, and composition work
- Search and filters by department, difficulty, roadmap phase, and completion status
- Daily sessions for 15, 30, 45, 60, and 90 minutes with focus selection, replacement, reordering, completion tracking, and session history
- Browser-local persistence for completion, notes, tempo records, roadmap selection, planner preferences, and practice history
- Validated JSON export and import
- Responsive desktop, mobile, and short-landscape layouts with no external dependencies

## Run locally

Serve this folder with any static web server, for example: python -m http.server 4173

Then open http://localhost:4173/.

The root files are the source checkout. dist/ contains a matching static copy for hosts that expect a deployment directory.
